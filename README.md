# BASIC PR reviewer

An operator-run GitHub App reviewer with disposable subscription CLI workers and durable per-pass coverage.

- [Repository policy and source scope](docs/configuration.md)
- [Service configuration, controls, health, backups and releases](docs/operations.md)
- [Worker containment and image acceptance](docs/worker.md)

Run `npm ci`, `npm run typecheck`, `npm run build`, and `npm test` for local synthetic validation. No production secrets are needed.
